# Update Summary — 2026-08-02

Bu dosya, 2026-08-02 tarihinde CrewCtl projesinde yapılan son sağlamlaştırma ve kalite iyileştirmelerini özetler.

## 1. CLI çalışma güvenilirliği

- CLI çalıştırılabilirlik kararı tek kurala bağlandı.
- Sadece `installed` olmak artık yeterli sayılmıyor.
- Şu sağlık durumları görev için bloklayıcı kabul ediliyor:
  - `auth-required`
  - `quota`
  - `failed`
  - `timeout`
  - `version-incompatible`
  - `not-installed`
- Şu durumlar geçici kabul edilip gereksiz bloklamaya yol açmıyor:
  - `testing`
  - `unknown`

## 2. Operatör ve agent fallback iyileştirmesi

- Seçili operatör CLI hazır değilse motor artık daha tutarlı fallback yapıyor.
- Uygun alternatif bir CLI varsa görev onunla devam ediyor.
- Uygun alternatif yoksa kullanıcıya daha net hata mesajı veriliyor.
- Uzman agent kataloğu da aynı “çalıştırılabilir CLI” kuralını kullanıyor.

## 3. Görev öncesi preflight kontrolü

- Dosya oluşturma/değiştirme isteyen görevlerde hazır bir `implementation` agent olup olmadığı görev daha kuyruğa girmeden kontrol ediliyor.
- Hazır implementation agent yoksa görev erken reddediliyor ve kullanıcı yönlendiriliyor.
- Bu kontrol web API yolunda ve motor akışında güçlendirildi.

## 4. Doctor komutu geliştirildi

`doctor` komutu artık sadece kurulu CLI listesini değil, gerçek hazır olma durumunu da raporluyor.

### Yeni davranışlar

- CLI sağlık testi sonucu rapora dahil ediliyor.
- “Kurulu ama kullanılamaz” durumları açıkça gösteriliyor.
- OpenCode için model hazır olma kontrolü rapora yansıtılıyor.
- Seçili operatör gerçekten çalıştırılabilir mi bilgisi rapora ekleniyor.

### Yeni seçenekler

- `crewctl doctor --json`
- `crewctl doctor --quick`
- `crewctl doctor --fix`

## 5. CLI task komutu iyileştirmesi

- `crewctl task` tarafına görev öncesi kalite kontrolü eklendi.
- Ancak bayat sağlık önbelleğinin komutu gereksiz yere kilitlememesi için aşırı sert ön kontrol geri yumuşatıldı.
- Sonuç: daha güvenli ama daha az yanlış negatif üreten bir akış elde edildi.

## 6. Test sağlamlaştırmaları

- `server-flow` testi boş port rezervasyonu kullanacak şekilde güçlendirildi.
- Windows tarafındaki aralıklı `ECONNRESET` dalgalanmasına karşı dar kapsamlı retry eklendi.
- Yeni CLI sağlık/fallback/preflight davranışları testlerle güvence altına alındı.
